# CTEM basics

CTEM is a continuous program for finding, prioritizing, and reducing exposures. It runs as a five-stage cycle:

1. **Scoping**: decide which business-critical assets and attack surfaces are in scope.
2. **Discovery**: inventory assets and find exposures (vulnerabilities, misconfigurations, identity risks).
3. **Prioritization**: rank exposures by exploitability, business impact, and compensating controls, not CVSS alone.
4. **Validation**: confirm an exposure is really exploitable (attack path analysis, breach-and-attack simulation, pentests).
5. **Mobilization**: route fixes to the owning teams and track them to closure.

When answering, tie the explanation to the stage the user is asking about, and give a concrete example where helpful.
